# 🧠 КвизЛэнд (QuizLand) — Web-приложение для викторин

Современный и отзывчивый веб-сайт для прохождения викторин и тестов, разработанный на фреймворке **Django** и полностью стилизованный клиентским CSS/JS-фреймворком **UIkit 3**. 

Проект построен по принципу **Single Page Application (SPA)** элементов: прохождение тестов, процессы авторизации и регистрации работают бесшовно через **AJAX (Fetch API)** без перезагрузки страниц.

## ✨ Ключевые особенности
* **Полный AJAX-flow:** Переключение вопросов, отправка ответов и вывод результатов происходят мгновенно и плавно с использованием встроенной анимации UIkit.
* **Динамическая авторизация:** Доступ к тестам ограничен. Формы входа и регистрации открываются в красивых модальных окнах (`uk-modal`) и обрабатываются на стороне сервера без перезагрузки интерфейса.
* **Автономия от интернета:** Все стили и скрипты UIkit 3 перенесены и подключены локально из папки `static`.
* **Удобное управление:** Встроенная админ-панель Django кастомизирована (`TabularInline`) для быстрого добавления вопросов и вариантов ответов на одной странице.
* **Безопасность:** Выход из системы и отправка форм защищены от CSRF-атак в соответствии со стандартами безопасности Django 5+.

## 🛠 Технологический стек
* **Backend:** Python, Django 5.x (Sessions, Auth, Templates, JsonResponse)
* **Frontend:** HTML5, JavaScript (Fetch API, DOM-компоненты), UIkit 3 CSS/JS Framework
* **База данных:** SQLite (локально)

## 🚀 Как запустить проект локально

### 1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd django-uikit-quiz
```

### 2. Настройте виртуальное окружение:
**Для Linux/macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```
**Для Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установите зависимости:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Выполните миграции базы данных:
```bash
python manage.py migrate
```

### 5. Создайте аккаунт администратора (для добавления тестов):
```bash
python manage.py createsuperuser
```

### 6. Запустите локальный сервер:
```bash
python manage.py runserver
```
Откройте в браузере: [http://127.0.0](http://127.0.0)  
Для перехода в админку и создания тестов используйте: [http://127.0.0admin/](http://127.0.0admin/)
